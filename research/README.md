# 研究资料

- [研究报告](reports/)：整理后的分析与案例时间线。
- [研究笔记](notes/)：来源、证据口径与核验记录。
- [教学理念摘录](../workshop-2027/philosophy.md)：围绕数据科学、教育、系统安全与数据治理的摘录和讨论问题。
- [参考链接](../workshop-2027/references.md)：论文、课程、机构与案例来源。

研究结论应结合各文件中的来源、核验状态及适用范围阅读。
- [原始资料](sources/)：用于研究的本地参考文件，具体来源和使用范围见相应报告。
- [课程研究资源调查](../workshop-2027/lab-survey.md)：研究项目和数据资源目录。

报告目录也包括可交互页面及与其配套的数据、方法文件；研究笔记按主题分文件夹保存。
