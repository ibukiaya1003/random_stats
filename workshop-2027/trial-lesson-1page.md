# 试讲一页纸：一个人怎样变成一个数字

> 45 分钟 · Zoom · 团队成员扮演学员 · 不用 API 和 coding agent，活动都在聊天区、分组讨论室和纸笔上完成\
> 主线：一个人被写进数据，要经过三道工序——**被定义 → 被分类 → 被用来做决定**。每一道都可能出错，而且错误不是平均分配的。

## 学习目标

1. 用「数字体检表」五问（来源、定义、分母、比较对象、不确定性）检查一个数字，并把一句观点改写成可以被证伪的命题。
2. 区分三种"看不见"：没被计数、被计错类别、被看见却被误读，并说出各自需要的研究方法。
3. 举例说明一个"合理的"计算规则如何在自动化后系统性地伤害特定人群，并说出质疑它需要知道什么。

## 三个要点怎么相扣

要点一的"定义"问题 → 到要点二变成"谁不在类别里、类别的线从谁身上算出来" → 到要点三变成"错误的类别被自动执行"。
