# 被计数的我们：数据女性主义与公共数据实践

> 唯理寒假工作坊 2027 ·「身份与社会」方向 · 课程设计草案（brainstorm 阶段，持续迭代）

- **时长**：5 天（3 天压缩版见文末）
- **人数**：建议 12–16 人，最多 20 人，4–5 组
- **主线**：数据与身份 —— 谁被计数，谁被看见
- **理论框架**：data justice、feminist data science、algorithmic fairness、computational social science、sociotechnical systems、data journalism、public-interest technology
- **议题方向**（讲师有研究积累）：医疗健康 / 医疗资源、性别、平台算法
- **最终成果**：每组一件 —— 交互式 dashboard 或数据新闻短篇，部署为网页
- **技术路径**：不教代码；学员用 DeepSeek API + coding agent 调用公共数据 API，完成一个可公开的成品

---

## 0. 设计原则

1. **理论—方法—本地问题三层结构**：理论告诉我们关注什么不平等或权力关系；方法论告诉我们怎样形成可信的证据；项目把二者转化为可以动手调查的问题。
2. **连接理论与真实数据**，而不是"用数据泛泛说明一个现象"。每个结论都要回答：我们能说什么，不能说什么。
3. **第一天不记录个人数据**，先学会消化铺天盖地的数据，再各自收集感兴趣的数据集。
4. **验证贯穿每天下午**：既验证数据，也验证 AI（agent 可能编造数据或静默丢行）。
5. **讲师提前准备**：GitHub 上 2–3 个示范项目 + 模板仓库，学员把时间花在提问与解释上，而不是环境和找数据上。

## 1. 与 2026 课表的关系

2026 课表（A–E 组共 27 门）没有一门数据或量化课程，但学员熟悉的议题与本课直接相通：

- 分类与身份建构：A01（人性边界）、A04（身体如何被归类与消费）
- 性别与女性声音：A08、D04、A03
- 日常治理与等待：B01（街头官僚、法律意识）
- 质性方法与民族志：B01、B04

本课补上的是：把这些直觉变成**可以检验的证据**的能力。

## 2. 每日安排

上午约 2.5 小时：共同阅读、案例分析、跨组讨论。下午约 3 小时：方法练习、分组制作、固定的验证环节。每天结束前 15 分钟进度分享与同伴反馈；Office Hour 个别辅导。

### Day 1｜在数据洪流里读懂一个数字

**上午 · 理论与案例**
- D'Ignazio & Klein, *Data Feminism* (MIT Press, 2020)，第 6 章 "The Numbers Don't Speak for Themselves"
- Lisa Gitelman (ed.), *"Raw Data" Is an Oxymoron* (MIT Press, 2013)，导论
- Gebru et al., "Datasheets for Datasets", *Communications of the ACM* (2021)
- 案例：拆解 2–3 条新闻数字 →「数字体检表」：来源 / 定义 / 分母 / 比较对象 / 不确定性
- 展示讲师在 GitHub 上的示范项目（成品长什么样）

**下午 · 方法与制作**
- 每人找一个感兴趣的数据集，用 Datasheets 格式写一页「数据说明书」
- 按兴趣分组（医疗健康 / 性别 / 平台算法）
- 配置 coding agent，第一次成功调用公共 API

**验证**：把 agent 拉到的数据与源网页逐条对照（行数、抽查值）

### Day 2｜分类即权力：数据如何给人分配身份

**上午 · 理论与案例**
- Bowker & Star, *Sorting Things Out: Classification and Its Consequences* (MIT Press, 1999)
- John Cheney-Lippold, *We Are Data* (NYU Press, 2017)
- Kimberlé Crenshaw, "Demarginalizing the Intersection of Race and Sex", *University of Chicago Legal Forum* (1989)
- *Data Feminism* 第 4 章 "What Gets Counted Counts"
- 案例：表格中的性别 / 类别字段设计；QSIDE 美国博物馆艺术家多样性研究（Topaz et al., *PLOS ONE*, 2019，可与本期艺术方向对话）；博物馆开放数据中"只标注女性、男性为默认值"的字段设计（具体机构待调 API 确认）

**下午 · 方法与制作**
- 对各组数据集做「分类审计」：类别如何定义、谁被合并、谁落入"其他"
- 用 agent 做分组统计

**验证**：缺失值审计（随机缺失还是有模式？）；交叉分类后各格样本量是否过小

### Day 3｜从数据层面证明系统性低代表（Data Feminism 深入）

**上午 · 理论与案例**
- *Data Feminism* 第 1–2 章（权力与挑战权力）
- Caroline Criado Perez, *Invisible Women* (2019)
- Mimi Onuoha, *The Library of Missing Datasets* (2016)
- Data + Feminism Lab：Data Against Feminicide —— 官方数据缺席时社群如何生产 counterdata
- 案例：临床试验中女性参与不足；参与-患病比 PPR = 样本中女性占比 ÷ 患病人群中女性占比（Scott et al., *JACC*, 2018）
- 案例：Gender Shades —— 商用人脸识别对深肤色女性错误率最高 34.7%，浅肤色男性最高 0.8%（Buolamwini & Gebru, *PMLR*, 2018）

**下午 · 方法与制作**
- 各组计算自己的代表性比值：样本占比 ÷ 基准人群占比

**验证**：换不同基准人群结论是否翻转（敏感性分析）；第二个独立数据源交叉核对

> 核心方法论：**低代表是一个比值，分母（基准人群）的选择本身就是一个论证。**

### Day 4｜算法、代理指标与自动化的不平等

**上午 · 理论与案例**
- Virginia Eubanks, *Automating Inequality* (2018)
- Ruha Benjamin, *Race After Technology* (2019)
- Safiya Noble, *Algorithms of Oppression* (2018)
- Dencik, Hintz, Redden & Treré, *Data Justice* (Sage, 2022)
- Obermeyer et al., *Science* (2019)：以"医疗花费"代理"健康需求"，系统性低估黑人患者需求（医疗 × 算法 × 代理指标）
- 公平定义的不可兼得：Kleinberg et al. (2016)；Chouldechova (2017)

**下午 · 方法与制作**
- 用 DeepSeek API 审计大模型本身：配对提示（只改姓名 / 性别，其他固定），比较职业推荐、简历评分或故事角色分配

**验证**：先写假设再跑实验；每条件重复多次、固定 temperature；区分"观察到的差异"与"能推断的机制"

### Day 5｜讲出可信的故事 → 结课展

**上午 · 理论与案例**
- The Markup 的方法论公开实践（"show your work"）
- Giorgia Lupi, Data Humanism 宣言 (2017)
- 不确定性的可视化
- 跨组互评圆桌：每组 5 分钟，其他组扮演"挑刺的编辑"

**下午 · 方法与制作**
- 定稿、部署、结课展
- 每件作品必附「方法与局限」面板：我们知道什么、从哪里知道、还不知道什么

## 3. 「不能直接声称什么」—— 贯穿全课的证据表

| 研究目标 | 优先方法 | 典型产出 | 不能直接声称什么 |
|---|---|---|---|
| 描述分布 | 描述统计、分层统计 | 分布图、比例、分位数 | 不能解释成因 |
| 比较群体或区域 | 标准化指标、分组比较、空间分析 | 差异图、比较表 | 不能把差异自动归因于身份或地域 |
| 检验相关 | 相关、回归、混杂审查 | 关联强度、置信区间 | 相关不等于因果 |
| 检查系统是否区别对待 | 标准化审计、配对比较、重复观察 | 同条件下的差异 | 不一定能确定内部机制或意图 |
| 研究谁没被记录 | 缺失审计、分类体系分析、访谈 | 缺失模式、盲点清单 | 没有记录不等于不存在 |

## 4. 项目选项（需备课时实测国内可访问性）

| 方向 | 研究问题示例 | 数据源 / API |
|---|---|---|
| 医疗健康 | 某类疾病的临床试验中女性、老年人是否低代表？ | ClinicalTrials.gov API v2；WHO GHO API（按性别分列指标） |
| 医疗资源 | 我所在城市不同街道到医院的公交时间差多少？ | 高德开放平台 POI 搜索 + 公交路径规划 |
| 性别 | 谁被收藏、谁被书写？ | 博物馆开放 API（如大都会博物馆）；World Bank Gender Data API；国家统计局《中国妇女发展纲要》统计监测报告（表格，由 agent 解析） |
| 平台算法 | 大模型的职业-性别联想是否有系统性偏向？ | DeepSeek API |

风险：Wikipedia / Wikidata 在中国大陆通常无法直接访问，不作为主选项；GitHub 访问不稳定，需准备国内可用的展示备选。

参考的 data justice 实践：QSIDE Institute（JustFair 联邦量刑数据、博物馆艺术家多样性数据、Data4Justice Accelerator：API 与爬虫采集、清洗、质性文本量化）；MIT Data + Feminism Lab（Data Against Feminicide）。

## 5. Coding agent 落地

- DeepSeek 官方提供 Anthropic 兼容接口 `https://api.deepseek.com/anthropic`，可直接接 Claude Code（模型名课前按官方文档核对）

- 讲师模板仓库：agent 提示词指南、数据抓取脚手架、验证清单、两个成品模板（ECharts 单页 HTML dashboard；数据新闻长文）
- 明确教学点：agent 会编造数据或静默丢行 —— 验证环节也是"监督 AI"的训练

## 7. 申请表草稿（第 11–23 题）

**11. 课程名称**：被计数的我们：数据女性主义与公共数据实践（备选：谁被看见？用公共数据调查身份与不平等）

**12.** 全新课程

**13.** 方法或工具练习；讨论／共同阅读；讲授／案例分析；创作／工作室实践

**14.（5 天）**
本课程围绕一个问题展开：当身份被表格、统计和算法所定义，谁被计数，谁又在数据中缺席？课程以数据女性主义（Data Feminism）、数据正义和算法公平为理论框架，以医疗健康、性别与平台算法为议题，带领文科背景的学员从"被数据描述的人"变成"能够检验数据的人"。学员不需要编程基础，将借助 AI 编程助手调用真实的公共数据接口，自主完成一项小型调查。

每天上午约 2.5 小时用于共同阅读、案例分析和跨组讨论；下午约 3 小时用于方法练习和分组制作，并设固定的"数据验证"环节。
- 第 1 天：读懂一个数字。拆解新闻中的统计，从来源、定义、分母、比较和不确定性五个角度检验数据；学员各自寻找感兴趣的数据集，撰写"数据说明书"，并按兴趣分组。
- 第 2 天：分类即权力。研读 Bowker & Star 与交叉性理论，审计数据集中的类别设计与缺失模式。
- 第 3 天：证明系统性低代表。以临床试验中的性别代表性等案例，学习代表性比值与基准人群的选择，并做敏感性检验。
- 第 4 天：算法与代理指标。研读 Eubanks、Benjamin 等人的著作，以配对实验审计大语言模型的偏向。
- 第 5 天：讲出可信的故事。跨组互评、修改定稿，举办结课展示。

每天结束前各组进行 15 分钟进度分享和同伴反馈，讲师在 Office Hour 个别辅导。

**15. 学员收获**
1. 能对日常遇到的数字提出关键问题：谁统计的，怎么定义的，分母是什么，和什么相比。
2. 理解"低代表"是一个需要论证的比值，能在公开数据中检验某一群体是否被系统性忽略。
3. 掌握与 AI 编程助手协作调用公共数据接口的流程，并能用核对、交叉验证、敏感性分析检查 AI 和数据的错误。
4. 完成一件附有方法与局限说明、可公开的数据作品（交互仪表盘或数据新闻）。

**16. 适合学员**
适合 16–26 岁、对性别、健康、技术与社会议题感兴趣的学员，尤其欢迎没有数学或编程背景的人文社科学生。必要条件：自带笔记本电脑（Windows 或 Mac），能阅读简单的英文网页和数据字段说明，参加开课前约 1 小时的线上环境配置。有编程或统计基础的学员可承担更复杂的数据处理或进阶任务。分组时混合不同背景，让每个人在提问、分析、写作或设计中找到位置。

**17. 结课展示**
每组完成一件可公开的数据作品（交互式仪表盘或数据新闻短篇），部署为网页，并附"方法与局限"说明：数据从哪里来、做了哪些验证、哪些结论不能下。结课展采用"开放工作室"形式，每组一个展位，观众用电脑或平板浏览作品并与学员交流。需要有投影的教室、每组一块屏幕和稳定网络。课后可将作品链接汇编为专题推送。

**20.** 建议 12–16 人；最多 20 人（4–5 组）
